# Portafolio de Ernesto Molina

Sitio estático en español e inglés. Incluye animación 2D, arte 3D, estudios de dibujo y cortometrajes y tesis.

## Publicar en GitHub Pages

1. Subir el contenido de esta carpeta a la raíz del repositorio público del sitio.
2. En Settings > Pages, elegir Deploy from a branch, la rama main y la carpeta / (root).
3. Guardar y esperar la publicación.

El archivo .nojekyll permite servir directamente los archivos HTML, CSS, JavaScript y medios. No requiere instalación ni compilación.

Las imágenes y videos conservan sus créditos y derechos de sus respectivos autores. Este repositorio no concede una licencia de reutilización de las obras.
